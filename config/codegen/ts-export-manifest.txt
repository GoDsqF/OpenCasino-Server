# TS-export manifest for `generatePackInterfacesTs` (CLAUDE.md §2.3).
#
# Source of truth for which Kotlin payload data classes are part of the WS wire
# contract and how their TypeScript counterparts are named in
# opencasino-docs/api/types.ts. An explicit allow-list — NOT a directory scan —
# because network/pack/** holds duplicate simple names across packages
# (GameUpdatePack / RoomPack / GameSettingsPack / DealerUpdatePack /
# PlayerHandUpdatePack live in 2-3 packages) plus dead legacy classes
# (deprecated*, abstract Blackjack*PlayerHandUpdatePack). types.ts also renames
# the wire types (poker/update.GameUpdatePack -> PokerGameUpdatePack).
#
# Format: two sections.
#   [interfaces]  FQCN = TsInterfaceName   (order here = emit order)
#   [typemap]     KotlinTypeName = TsType  (how referenced enum/domain types map)
# Lines starting with '#' and blank lines are ignored.
